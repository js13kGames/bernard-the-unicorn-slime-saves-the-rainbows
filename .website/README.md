## Controls

- **Arrow keys**: Move player / cursor in menus
- **Enter / Space**: Select menu item
- **Z / Backspace**: Undo a move
- **R**: Restart the level
- **Escape / Enter**: Open pause menu


## Other stuff: 

- I'm aware of all graphical glitches in the game. They were side effects of how the rendering works.
- No AI was used in the production. Because I didn't need to.
